👋 About Me

สวัสดีค่ะ ดิฉัน นางสาวภัทรพร ตั้งแต่ง นักศึกษาชั้นปีที่ 3 สาขาวิศวกรรมซอฟต์แวร์ มหาวิทยาลัยพะเยา มีความสนใจด้าน Software Testing และ Quality Assurance (QA)

มีประสบการณ์จากโครงงานในมหาวิทยาลัยในการวิเคราะห์ Requirement, ออกแบบ Test Scenario และ Test Case, Functional Testing และ Manual Testing รวมถึงมีพื้นฐานด้าน Automated Testing ด้วย Playwright และ Robot Framework
